# 🎣 Fishing Roguelite (ชื่อชั่วคราว)

เกมตกปลากึ่ง **Roguelite RPG**: ออกเรือไปสำรวจ เลือกทำเล ล่าปลาหายาก แล้วกลับมาอัปเกรดเรือ เบ็ด และตัวละคร ให้ไปได้ไกลขึ้นและลึกขึ้นเรื่อยๆ

> **สถานะ:** 💭 ขั้นรวบรวมไอเดีย ยังไม่ได้เริ่มเขียนโค้ด

## ความรู้สึกที่อยากให้ผู้เล่นได้
> "ตอนเด็กชอบเล่นเกมแนวนี้มาก มีความสุขทุกครั้งที่ตกปลาระดับหายากได้"

เป้าหมายหลักของเกมคือช่วงเวลา **"ได้แล้ว!!"** ตอนดึงปลาหายากขึ้นมา ทุกระบบในเกมต้องช่วยให้ช่วงเวลานี้รู้สึกพิเศษที่สุด

## เกมอ้างอิงที่ควรลองเล่น / ศึกษา
- **Dredge**: ตกปลา อัปเกรดเรือ มีบรรยากาศลึกลับ
- **Cat Goes Fishing**: ตกปลาเรียบง่ายแต่ติดมาก อัปเกรดเบ็ดและเรือ
- **Ridiculous Fishing**: มินิเกมตกปลาที่สนุกมากบนมือถือ
- **Fisch** (Roblox): เกมตกปลา Free-to-Play ที่มีคนเล่นเยอะ
- **Stardew Valley**: ระบบตกปลาและสารานุกรมปลา
- **Hades / Slay the Spire**: ต้นแบบระบบ Roguelite
