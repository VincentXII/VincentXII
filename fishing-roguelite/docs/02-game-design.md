# 02 — ออกแบบระบบเกม (ร่างแรก)

> ขยายจากไอเดียดั้งเดิม ทุกตัวเลขเป็นค่าตั้งต้นไว้ปรับทีหลัง

---

## 1. วงจรการเล่นหลัก (Core Loop)

```
🏘️ อยู่ในเมือง                         ⛵ ออกทะเล (1 รอบ = 1 Run)
├─ ขายปลา                             ├─ เลือกเส้นทาง / ทำเลบนแผนที่
├─ อัปเกรดเรือ / เบ็ด / ตัวละคร  ──►   ├─ ตกปลา (มินิเกม)
├─ ซื้อเหยื่อ / น้ำมัน / เสบียง           ├─ เจอเหตุการณ์สุ่ม (พายุ ซากเรือ พ่อค้ากลางทะเล)
└─ รับภารกิจ / ดูสารานุกรมปลา         ├─ เก็บของบัฟชั่วคราว (เฉพาะรอบนี้)
        ▲                             └─ ตัดสินใจ: "ไปต่อให้ลึกขึ้น" หรือ "กลับฝั่ง"
        │                                        │
        └──────── กลับฝั่งพร้อมปลาและของที่ได้ ◄────┘
```

### ส่วนที่เป็น Roguelite
- **ทุกรอบที่ออกเรือ แผนที่ทำเลจะสุ่มใหม่** (ทำเลไหนมีฝูงปลา ทำเลไหนมีอันตราย)
- **ของบัฟชั่วคราว (Relic / เครื่องราง)** หาได้ระหว่างรอบ ใช้ได้เฉพาะรอบนั้น เช่น
  - 🐚 *เปลือกหอยนำโชค*: โอกาสเจอปลาหายาก +10%
  - 🧭 *เข็มทิศเก่า*: เห็นทำเลลับบนแผนที่
  - 🦈 *ฟันฉลาม*: ปลาตัวใหญ่ดิ้นช้าลง
  - ของบางชิ้นรวมกันแล้วเกิด **combo** (synergy)
- **เสี่ยงหรือไม่เสี่ยง?** น้ำมันและเสบียงมีจำกัด ยิ่งไปลึกยิ่งได้ปลาดี แต่ถ้าเรือจมหรือน้ำมันหมด **จะเสียปลาในห้องเก็บบางส่วน**
- **ความก้าวหน้าถาวร (Meta Progression)** ได้แก่ เงิน อัปเกรด สารานุกรม และเลเวลตัวละคร ไม่หายแม้รอบนั้นล้มเหลว

---

## 2. มินิเกมตกปลา 🎣 (หัวใจของเกม ต้องสนุกที่สุด)

1. **เหวี่ยงเบ็ด**: กดค้างเพื่อกำหนดระยะ ยิ่งไกลยิ่งเจอปลาใหญ่ แต่แม่นยำยากขึ้น
2. **รอปลากิน**: ทุ่นกระตุก แล้วต้องกดให้ทันจังหวะ ช้าไปปลาหนี
3. **ดึงปลา (Reeling)**: มีแถบ**แรงตึงสาย**
   - ดึงแรงเกินไป → สายขาด
   - ปล่อยมากเกินไป → ปลาหลุด
   - **ปลาแต่ละชนิดมีนิสัยต่างกัน** เช่น พุ่งเร็ว ดำลึก กระโดด หรือดิ้นเป็นจังหวะ
4. **ได้ปลา!**: แสดงชนิด ขนาด น้ำหนัก และความหายาก พร้อมเอฟเฟกต์ตามระดับ

> 💡 ปลาหายากต้องมี**สัญญาณบอกล่วงหน้า** เช่น ทุ่นเรืองแสง น้ำวน หรือเสียงพิเศษ ให้ผู้เล่นใจเต้นตั้งแต่ก่อนดึงขึ้นมา

---

## 3. ระดับความหายาก ✨

| ระดับ | สี | ตัวอย่างโอกาสเจอ |
|---|---|---|
| ธรรมดา (Common) | ⚪ เทา | 60% |
| ไม่ธรรมดา (Uncommon) | 🟢 เขียว | 25% |
| หายาก (Rare) | 🔵 น้ำเงิน | 10% |
| มหากาพย์ (Epic) | 🟣 ม่วง | 4% |
| ตำนาน (Legendary) | 🟡 ทอง | 0.9% |
| เทพนิยาย (Mythic) | 🔴 รุ้ง/แดง | 0.1% |

ระบบความหายากนี้ใช้ร่วมกันทั้ง **ปลา เบ็ด ม็อด และของบัฟ**

## 4. เรือ ⛵

### แนวคิด: เรือแต่ละลำมี "บทบาท" ไม่ใช่แค่ลำไหนเก่งกว่า
| เรือ | จุดเด่น | จุดด้อย | ปลดล็อกพื้นที่ |
|---|---|---|---|
| 🚣 เรือพาย | ถูก เข้าทำเลตื้นหรือคลองแคบได้ | ช้า ห้องเก็บเล็ก | แม่น้ำ / ชายฝั่ง |
| 🚤 เรือเร็ว | ไปได้ไกลต่อน้ำมัน 1 ถัง | ห้องเก็บเล็ก ทนพายุไม่ได้ | หมู่เกาะ |
| 🛳️ เรือประมง (Trawler) | ห้องเก็บใหญ่ ทนทาน | ช้า กินน้ำมัน | ทะเลเปิด |
| 🧊 เรือตัดน้ำแข็ง | ฝ่าน้ำแข็งได้ | แพงมาก | ทะเลน้ำแข็ง |
| 🔬 เรือวิจัย | มีโซนาร์ เห็นปลาหายากใต้น้ำ | ห้องเก็บเล็ก | ร่องลึกก้นสมุทร |

### ช่องม็อดของเรือ (Mod Slots)
เรือแต่ละลำมีช่องใส่ม็อดจำนวนไม่เท่ากัน เช่น
- **เครื่องยนต์**: เร็วขึ้น / ประหยัดน้ำมัน
- **ตัวเรือ**: ทนพายุ / ทนชน
- **ห้องเก็บ**: จุได้มากขึ้น / มีห้องเย็นทำให้ปลาไม่เสีย
- **อุปกรณ์**: โซนาร์ ไฟส่องใต้น้ำ เรดาร์พายุ

> ตัวเรือเป็นตัวกำหนดว่า**ไปที่ไหนได้** ส่วนม็อดเป็นตัวกำหนด**สไตล์การเล่น**

## 5. เบ็ดตกปลา 🎣

### ส่วนประกอบ (แต่ละชิ้นเปลี่ยนได้)
- **คันเบ็ด**: แรงดึง ความยาวระยะเหวี่ยง
- **รอก**: ความเร็วการม้วนสาย
- **สาย**: รับแรงตึงได้เท่าไร
- **ตะขอ**: โอกาสที่ปลาหลุด
- **เหยื่อ**: กำหนด**ชนิดปลา**ที่จะมากิน ⭐ ตัวเลือกที่มีผลมากที่สุด

### ม็อดของเบ็ด (ตัวอย่าง)
- 🔥 *สายเพลิง*: ปลาเหนื่อยเร็วขึ้น
- 🧲 *ตะขอแม่เหล็ก*: มีโอกาสเกี่ยวสมบัติจากก้นทะเล
- 🌙 *รอกจันทรา*: ตอนกลางคืนดึงแรงขึ้น
- 🍀 *ทุ่นนำโชค*: เพิ่มโอกาสเจอปลาหายาก
- ⚡ *สายคู่*: มีโอกาสได้ปลา 2 ตัวในครั้งเดียว

### เบ็ดตำนาน
เบ็ดระดับ Legendary ขึ้นไปมี**ความสามารถพิเศษเฉพาะตัว**และมีเรื่องราวประกอบ เช่น เบ็ดของนักตกปลาในตำนานที่หายสาบสูญไป

## 6. แผนที่: เมือง → ทำเล 🗺️

```
🌏 โลก
├─ 🏘️ เมือง A (เริ่มต้น)      ความยาก ★☆☆☆☆   ต้องใช้: เรือพาย
│   ├─ ท่าเรือ
│   ├─ ปากแม่น้ำ
│   └─ ป่าชายเลน
├─ 🏝️ เมือง B (หมู่เกาะ)       ความยาก ★★☆☆☆   ต้องใช้: เรือเร็ว
│   ├─ แนวปะการัง
│   ├─ อ่าวลับ
│   └─ ซากเรืออับปาง
├─ 🌊 เมือง C (ทะเลเปิด)       ความยาก ★★★☆☆   ต้องใช้: เรือประมง
├─ 🧊 เมือง D (ขั้วโลก)         ความยาก ★★★★☆   ต้องใช้: เรือตัดน้ำแข็ง
└─ 🌑 ร่องลึกก้นสมุทร         ความยาก ★★★★★   ต้องใช้: เรือวิจัย + ม็อดพิเศษ
```

- แต่ละเมืองมี**ร้านค้า ตลาดปลา ช่างเรือ และ NPC ภารกิจ**เป็นของตัวเอง
- **ราคาปลาแต่ละเมืองไม่เท่ากัน** เปิดทางให้เล่นแบบเป็นพ่อค้าได้
- แต่ละเขตมี**ปลาบอส (ปลาตำนาน)** 1 ตัว พร้อมเรื่องราวของมันเอง

## 7. ตัวละครและสเตตัส 🧑

| สเตตัส | ผล |
|---|---|
| 💪 พลัง (Strength) | ดึงปลาตัวใหญ่ได้ แรงตึงสายเพิ่มช้าลง |
| 🍀 โชค (Luck) | โอกาสเจอปลาหายากและของดี |
| 👁️ สายตา (Perception) | เห็นสัญญาณปลาหายาก จังหวะกดกว้างขึ้น |
| 🫁 อึด (Stamina) | ตกปลาได้นานขึ้นต่อรอบ |
| 🧭 เดินเรือ (Navigation) | ประหยัดน้ำมัน หลบพายุได้ |

- เลเวลอัปจากการตกปลา แล้วได้แต้มไปเพิ่มสเตตัส
- อาจมี **Skill Tree** แยก 3 สายให้เลือก: **นักล่าปลายักษ์ / นักสะสมปลาหายาก / พ่อค้า**

---

## 8. อีเวนต์และซีซัน 🏆

ทำได้ทั้งในเกมเล่นคนเดียวและเกมออนไลน์ (ดูรายละเอียดใน `04-business-model.md`)

- **ฤดูกาลในเกม** (ร้อน / ฝน / หนาว): ปลาบางชนิดออกมาเฉพาะบางฤดู
- **การแข่งขันตกปลา**: แข่งกับ NPC หรือผู้เล่นจริง ตามปลาที่ใหญ่ที่สุด
- **ซีซันพิเศษ** เช่น เทศกาลลอยกระทง หรือปีใหม่ มีปลาและของรางวัลเฉพาะซีซัน

---

## 9. สารานุกรมปลา 📖 (ตัวสร้างความอยากเก็บให้ครบ)
- ปลาที่ยังไม่เคยจับได้จะแสดงเป็น**เงาดำ** พร้อมคำใบ้ว่าอยู่ที่ไหนและออกตอนไหน
- บันทึก**สถิติตัวที่ใหญ่ที่สุด**ของแต่ละชนิด
- เก็บครบแต่ละหมวด แล้วได้รางวัลหรือปลดล็อกของใหม่
