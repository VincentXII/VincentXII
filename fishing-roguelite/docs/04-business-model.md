# 04 — โมเดลธุรกิจ: Free-to-Play หรือซื้อขาด?

## เปรียบเทียบ

| | 🛒 ซื้อขาด (Premium) | 🆓 Free-to-Play |
|---|---|---|
| **รายได้** | ขายครั้งเดียว (เช่น $5–15) | โฆษณา / ไอเท็ม / Season Pass |
| **ค่าเซิร์ฟเวอร์** | ✅ แทบไม่มี | ❌ มี และเพิ่มตามจำนวนผู้เล่น |
| **ต้องอัปเดตตลอด** | ไม่จำเป็น (อัปเดตเมื่อพร้อม) | ✅ จำเป็น ต้องมีอีเวนต์ใหม่ตลอด |
| **เรื่องโกง** | ไม่ค่อยสำคัญ (เล่นคนเดียว) | สำคัญมาก ต้องตรวจฝั่งเซิร์ฟเวอร์ |
| **ความยากของงาน** | 🟢 ทำคนเดียวได้ | 🔴 ต้องมีทีมหรือต้องทำงานหนักมาก |
| **ออกแบบเกม** | ยิ่งสนุก ยิ่งขายดี | ต้องออกแบบให้คนอยากจ่าย ซึ่งอาจทำลายความสนุก |
| **เหมาะกับไอเดียนี้** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## 💡 คำแนะนำ: เริ่มจาก "เกมเล่นคนเดียว ซื้อขาด บน Steam"

**เหตุผล**
1. **Roguelite เข้ากับเกมซื้อขาด** เพราะผู้เล่น Steam ชอบเกมแนวนี้และยอมจ่าย
2. **ไม่มีค่าเซิร์ฟเวอร์** ไม่ต้องกังวลเรื่องคนโกงหรือเซิร์ฟล่ม
3. **ระบบที่คิดไว้ทั้งหมดทำได้ในเกมออฟไลน์** รวมถึงซีซันและอีเวนต์ (ใช้ฤดูกาลในเกมแทน)
4. **ความสุขตอนได้ปลาหายากจะบริสุทธิ์** เพราะไม่มีระบบเติมเงินเพื่อซื้อโอกาสมาแทรก
5. Steam มี **Next Fest** ให้ปล่อยเดโมฟรีเพื่อเก็บ Wishlist ก่อนขายจริง

**ค่าใช้จ่ายโดยประมาณ** (ควรเช็กราคาล่าสุดอีกครั้ง)
- Steam: ค่าลงเกมประมาณ $100 ต่อเกม และ Steam หักส่วนแบ่งจากยอดขาย
- Google Play: ค่าสมัครประมาณ $25 จ่ายครั้งเดียว

## 🗺️ แผนแบบขั้นบันได
```
ขั้น 1: เดโมฟรีบนเว็บ / itch.io     → ทดสอบว่าคนชอบไหม
ขั้น 2: ขายบน Steam (ซื้อขาด)        → รายได้หลัก
ขั้น 3: พอร์ตลงมือถือ                → ขายแบบซื้อขาด หรือเล่นฟรีแล้วจ่ายครั้งเดียวเพื่อปลดล็อกเกมเต็ม
ขั้น 4: (ถ้าเกมดัง) เพิ่มระบบออนไลน์   → ตารางคะแนน การแข่งขันประจำสัปดาห์ หรือภาคต่อแบบ F2P
```

## ถ้าอยากทำ F2P จริงๆ
- ขายเฉพาะ**ของแต่งตัว** (สกินเรือ ชุดตัวละคร เอฟเฟกต์ตอนได้ปลา) **ไม่ขายพลัง**
- **Season Pass** แบบมีรางวัลฟรีและรางวัลพรีเมียม
- ⚠️ ถ้ามีระบบสุ่ม (กาชา) ต้องเปิดเผยอัตราการออกตามกฎของสโตร์
- ทางเลือกน่าสนใจ: ทำบน **Roblox** ซึ่งมีผู้เล่นและเซิร์ฟเวอร์ให้อยู่แล้ว เกมตกปลาบน Roblox อย่าง *Fisch* เคยประสบความสำเร็จมาแล้ว แต่ต้องใช้ภาษา Lua และแบ่งรายได้ให้แพลตฟอร์ม
